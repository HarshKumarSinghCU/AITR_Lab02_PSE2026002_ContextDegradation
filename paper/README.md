# Manuscript source

- `main.tex` — two-column reproducibility-focused manuscript draft.
- `references.bib` — bibliography for the cited dataset, retrieval, embedding, long-context, and NLI methods.

## Build

In Overleaf, set `main.tex` as the main document and upload the `paper/` directory. Locally:

```bash
cd paper
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

The current manuscript is deliberately a protocol/reproducibility draft. It explains the controlled synthetic contradiction, the three systems, and the H1/H3/H4 proxy metrics. It does not make new numerical claims because the updated code has not yet been executed. Complete the Results section only after auditing the run-level CSV and summary outputs generated by the notebook.
