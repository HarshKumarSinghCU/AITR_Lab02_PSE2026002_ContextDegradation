# Empirical Evaluation of Context-Window Degradation in Multi-Document Research Synthesis

**Author:** Harsh Kumar Singh (`PSE2026002`), IIIT Allahabad  
**Course:** AI Tools for Research — Post-Mid-Sem Implementation Study

This repository contains a controlled study of context-window degradation in multi-document scientific synthesis.

## Research question

How do corpus scale (`k ∈ {5, 15, 25}`) and target-evidence position (`start, middle, end`) affect (H1) retention of mid-document methodological qualifiers and (H4) detection of contradictory findings? To what extent can edge-salience ordering and claim-level NLI verification mitigate these failures?

## Experimental design

The benchmark follows the assignment's factorial structure: 5 pilot clusters produce 135 conditions (5 clusters × 3 corpus sizes × 3 positions × 3 systems). The larger run uses 15 clusters (405 conditions).

Three systems are compared:

1. **Baseline 1 — Full Context:** all documents are supplied in the original order.
2. **Baseline 2 — Dense RAG:** the top four passages selected by BGE dense retrieval are supplied without edge reordering.
3. **Proposed Figure 2 pipeline:** dense ranking, alternating edge-salience ordering, generation, and a DeBERTa NLI verification pass over the two top-ranked studies. When verification is below the configured threshold, a focused answer is regenerated from those studies.

The stimulus builder uses PubMedQA `pqa_labeled` records as source material. Following the provided assignment implementation, it constructs a positive target study, a paired *synthetic contradictory replication*, and topic-matched distractors. The contradiction sentence is an experimental counterfactual inserted by the benchmark; it must not be presented as a factual statement from a published PubMedQA record.

## Reproduce in Google Colab

1. Select **Runtime → Change runtime type → T4 GPU**.
2. Clone the repository and install its dependencies:

```bash
git clone https://github.com/HarshKumarSinghCU/AITR_Lab02_PSE2026002_ContextDegradation.git
cd AITR_Lab02_PSE2026002_ContextDegradation
pip install -r requirements.txt
```

3. Run the environment check and 5-cluster pilot:

```bash
python scripts/env_sanity_check.py
python scripts/run_factorial_experiment.py --clusters 5
python scripts/plot_from_csv.py
```

Use `--clusters 15` for the 405-condition evaluation when the Colab GPU quota permits. The first run downloads the selected model weights and PubMedQA data. Greedy decoding, seed 42 and a 300-token generation limit are set in the experiment configuration.

## Outputs

The experiment writes `results/experiment_results.csv`, `results/summary_metrics.csv`, and `results/run_metadata.json`. The plotting script generates the figures from the run-level CSV. No result is hard-coded: plotting fails clearly when the source CSV is missing.

## Metrics and interpretation

- **Headline recall:** fraction of positive-study answer keywords retained in the synthesis.
- **H1 qualifier retention:** binary retention of at least one controlled qualifier phrase (100 or 0).
- **H4 contradiction detection:** binary appearance of contradiction markers (100 or 0).
- **H3 NLI citation faithfulness:** fraction of cited sentences supported by at least one cited document at the configured entailment threshold.
- **Wall-clock latency:** time spent in each system, including retrieval and verification for systems that use them.

H1 and H4 are controlled lexical checks, not a substitute for blinded human annotation. NLI scores are model-based proxies and are not calibrated probabilities.
