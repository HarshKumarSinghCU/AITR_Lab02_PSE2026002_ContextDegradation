# Colab notebook

Open `colab_experiment_runner.ipynb` in Google Colab, select a T4 GPU, and run the cells top to bottom. The notebook clones this repository, installs the requirements, records environment details, and launches the five-cluster pilot. For the extended run, change the `--clusters` argument from 5 to 15 after the pilot has been checked.

The notebook does not contain fabricated execution outputs. Save and commit the executed notebook only after the experiment has completed.
